# Profile Contract

This surface owns the portable Profile directory, identifiers, chats, turns,
skills, artifacts, versioning, and forward-compatibility rules. The current
storage contract is in `docs/STORAGE.md`.

- `layout.md` defines the portable Profile tree.
- `chats.md` defines chat persistence and checkpoint ordering.
- `artifacts.md` defines file identity and references.
- `versioning.md` defines migrations and compatibility.
