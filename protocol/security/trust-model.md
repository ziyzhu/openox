# Trust Model

Status: Normative.

The user, selected Host, and installed application are trusted to enforce local
policy. Model output, VM source, service repositories, remote content, web
pages, MCP servers, imported Profiles, and transport peers are untrusted input.

Trust does not transfer through text. A skill, service file, model response, or
virtual path cannot grant itself authority. The Host derives authority from the
active Profile, mounted source, selected service, platform policy, and an
explicit user decision where required.
