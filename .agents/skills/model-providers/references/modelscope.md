# ModelScope

## Official destinations

- Website: [ModelScope](https://modelscope.cn/)
- API Inference documentation: [Usage limits](https://modelscope.cn/docs/model-service/API-Inference/limits)
- Account management: ModelScope access tokens. The current Ox deep link belongs in the provider source.

## Ox account placement

Ox presents ModelScope API Inference only in China. The service is free for development but requires a linked, identity-verified Alibaba Cloud account. Its models, quotas, and concurrency limits can change, and it does not provide a production SLA.
