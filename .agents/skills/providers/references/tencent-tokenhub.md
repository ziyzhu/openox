# Tencent TokenHub

## Official destinations

- Product: [Tencent Cloud TokenHub](https://cloud.tencent.com/product/tokenhub)
- Developer documentation: [TokenHub API usage](https://cloud.tencent.com/document/product/1823/130078)
- New-user trial: [Free trial package](https://cloud.tencent.com/document/product/1823/130053)
- Account management: TokenHub API keys. The current Ox deep link belongs in the provider source.

## Ox account placement

Ox presents the Guangzhou TokenHub endpoint only in China. Do not combine it with the separate Singapore endpoint or Token Plan credentials without an explicit regional integration.

The general API is a first-run trial option. Free quotas are time-limited, and users can separately enable postpaid billing on their Tencent Cloud account.
