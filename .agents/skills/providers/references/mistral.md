- Account management: Mistral AI Console API keys. The current Ox deep link belongs in the provider source.

## Ox account placement

Ox presents the Mistral API in Global. Mistral enables API access in Free mode without requiring a credit card. Users still create and paste an API key, and Free mode has provider-managed usage and rate limits.
